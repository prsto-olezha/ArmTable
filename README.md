# ArmTable 💪

Десктопное приложение для проведения турниров **по круговой системе** (каждый играет
с каждым) — задумано для армрестлинга, но подходит для любого спорта без ничьих.
Веб-интерфейс внутри нативного окна, работает **полностью офлайн**.

## Возможности

- Несколько турниров, в каждом — произвольное число категорий.
- Регистрация участников: **ФИО + вес**, жеребьёвка стартовых номеров (кнопка «перемешать»).
- Формат боя на выбор (задаётся на турнир, переопределяется в категории):
  - победа/поражение;
  - бой до 2 побед (счёт 2:0 / 2:1);
  - бой до 3 побед (3:0 / 3:1 / 3:2).
- Автоматическое расписание по **таблицам Бергера**: туры генерируются сразу,
  при нечётном числе участников один пропускает тур.
- Ввод результата в один клик (кнопки-пресеты счёта), живая таблица положения.
- Исправление любого результата до конца турнира; снятие участника
  (технические поражения в оставшихся боях) и возврат.
- Итоговое положение с тай-брейками: **очки → личные встречи → разница раундов → стартовый номер**.
- Итоги: пьедестал по каждой категории, полная история встреч.
- **Экспорт в Excel** одним файлом: лист «Призёры» + по листу на категорию
  (расписание туров, кросс-таблица, итоговое положение с медальной заливкой).

## Технологии

- [Tauri 2](https://tauri.app) — нативная оболочка (Rust), окно с системным WebView.
- Vue 3 + TypeScript + Vite, Pinia, vue-router.
- ExcelJS — генерация .xlsx полностью офлайн.
- Данные хранятся в JSON-файле:
  - Linux: `~/.local/share/com.armtable.app/armtable-data.json`
  - Windows: `%APPDATA%\com.armtable.app\armtable-data.json`
- Без интернета: приложение не делает никаких сетевых запросов.

## Разработка

```bash
npm install
npm run tauri dev      # окно приложения с горячей перезагрузкой
npm run dev            # только фронтенд в браузере (данные в localStorage)
```

Фронтенд умеет работать и без оболочки Tauri (в обычном браузере, данные в
localStorage) — это удобно для отладки. Внутри Tauri данные пишутся в файл
через Rust-команды `load_data` / `save_data`.

## Сборка

```bash
npm run tauri build    # deb/AppImage (Linux) или msi/nsis (Windows)
```

Готовые установщики под обе платформы собирает GitHub Actions
(`.github/workflows/build.yml`) — артефакты появляются в разделе Actions.

### Зависимости для сборки на Linux (Ubuntu/Debian)

```bash
sudo apt-get install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev patchelf
```

Плюс Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

## Структура

```
src/                  фронтенд (Vue 3 + TS)
  views/              экраны: список турниров, настройка, проведение, итоги
  components/         карточка категории в конструкторе
  lib/berger.ts       генератор кругового расписания
  lib/standings.ts    очки и тай-брейки
  lib/excel.ts        экспорт xlsx (ExcelJS)
  lib/storage.ts      JSON-хранилище (Tauri FS / localStorage)
  stores/app.ts       состояние приложения (Pinia)
src-tauri/            оболочка Tauri (Rust): команды load_data/save_data
```
